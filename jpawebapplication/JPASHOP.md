# 엔티티 생성 시 주의 사항
  - 1:N 테이블일 경우 연관 관계의 주인은 N(FK가 있는 테이블)이 주인이다.
    - 1을 연관 관계의 주인으로 정하면 관리하지 않는 N테이블의 외래 키 값이 업데이트 되므로 관리와 유지보수가 어렵다.
    - 추가적으로 별도의 업데이트 쿼리가 발생하는 성능 문제도 있다.
  - 실무에서 @ManyToMany는 사용하지 말자 ! 
  - 실무에서 Getter는 열어두고 Setter는 꼭 필요할 경우에만 사용하자. 
  - 모든 연관관계는 지연로딩으로 설정 !
    - @XToOne 관계는 기본이 즉시로딩므로 직접 지연로딩으로 설정해야 한다.
    - 관련된 엔티티를 함께 DB에서 조회해야 하면, fetch join 또는 엔티티 그래프 기능을 사용한다.
  - 컬렉션은 필드에서 초기화 하자 !
    - 컬렉션은 필드에서 바로 초기화 하는 것이 안전하다.
    - null 문제에서 안전하다
